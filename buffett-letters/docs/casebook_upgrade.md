# 从知识库升级为投资案例库

## 1. 现在这个网页为什么会显得浅

我看了 [buffett-letters-eir.pages.dev](https://buffett-letters-eir.pages.dev/) 的首页和公司页样本，它的优点是：

- 导航和交叉链接已经很多
- 主题词、公司、人物的索引做得比较全
- 单页读起来顺，不会太学术

但它的核心单元仍然是「公司介绍」，而不是「投资案例」。这会带来四个明显问题：

- 它把 `公司本身优秀` 和 `巴菲特当时为什么出手` 混在一起写，缺少时点感。
- 它大量使用后见之明，却没有把 `买入当年看到的证据` 和 `多年后的验证结果` 分开。
- 它把 `买入`、`持有`、`加仓`、`不卖`、`卖出` 放在一段叙事里，没有拆成可核对的阶段。
- 它虽然列了「历年提及」，但没有把页码、原句、持仓表格、成本与市值变化连起来。

所以读者会觉得「像在讲故事」，但很难回答真正关键的问题：

- 当时便宜到什么程度？
- 当时市场和伯克希尔自己的资金环境是什么？
- 是几年后开始被市场重新定价的？
- 如果没卖，为什么没卖；如果卖了，卖点是什么？

## 2. 页面单位应该从 company 改成 investment case

更好的做法是把「公司页」降级为目录页，把真正分析单元升级为 `investment case`。

### Company Page

公司页只负责回答：

- 这家公司在巴菲特体系里出现过几次
- 分别对应哪些投资阶段或证券类型
- 每个 case 的入口在哪里

### Investment Case Page

案例页才回答：

- 进入时点
- 成本与价值
- 市场环境
- thesis
- thesis 被验证或被破坏的过程
- 卖出或继续持有的逻辑

这一步很关键，因为同一家公司常常不止一个 case。

例如：

- 美国运通至少要区分 `1964 危机买入`、`1991 PERCs`、`1994-1995 普通股扩仓`
- 高盛要区分 `2008 优先股/认股权证` 和后来普通股变化
- IBM、航空股这类则要能明确显示 `后来退出`

## 3. 每个案例页的推荐结构

建议每个案例页固定为下面八块。

### A. 一页结论卡

放在最上面，五秒内让读者抓到主线：

- `买入窗口`
- `完成建仓时间`
- `总成本`
- `当前状态`：持有 / 已退出 / 部分退出
- `核心 thesis`
- `结论类型`：低估修复 / 危机反转 / 伟大公司合理价 / 特殊条款交易

### B. 买入时的环境

这一块只写「当时」，不掺杂后面发生的结果：

- 大盘与并购环境是否便宜
- 伯克希尔当时的资金规模与机会约束
- 行业或公司当时处于什么阶段
- 巴菲特在当年信里对机会集的评价

### C. 价值与价格

这块是你最在意、也是原网页最缺的部分。

至少要拆成：

- `quoted price`：当年买入或建仓区间的价格/市值/持仓表格
- `value anchors`：巴菲特当时真正看的锚点
- `why not exact DCF`：很多年份他不会给出精确内在价值数字，这时就要写清楚他是靠什么替代判断的

可展示的数据字段：

- 初始持股数
- 初始成本
- 当年末市值
- 完成建仓后的总成本
- 股息起点
- 若干关键年份的市值/分红变化

### D. Thesis 拆解

不要再写成散文，改成卡片化结构：

- `business quality`
- `moat`
- `management`
- `capital intensity`
- `reinvestment runway`
- `expected shareholder economics`

### E. 持有期验证

这部分回答「几年后开始上涨」。

最好的方式不是只说股价涨了，而是把三条线分开：

- 经营线：收入、利润、股息、回购、海外扩张、ROE 等
- 市场线：持仓市值从多少变到多少
- 认知线：巴菲特后来是如何回顾这笔投资的

### F. 卖出逻辑或不卖逻辑

这个字段必须显式存在，不能省略。

因为很多案例压根没卖：

- 如果 `仍持有`，要写「没有卖出的原因」而不是假装存在卖点。
- 如果 `已退出`，要明确是 `估值过高`、`thesis 受损`、`资本再配置` 还是 `错误认亏`。

### G. 证据账本

这一块决定内容深度。

每条结论都尽量落到：

- `年份`
- `页码`
- `原文摘录`
- `解释`
- `标签`：buy / hold / add / sell / valuation / market-context

### H. 语料边界与缺口

不要硬编。

如果本地只有 `1977-2024` 股东信，就明确标注：

- 该案例是否缺少首次买入时的原始材料
- 哪些数字来自后续回顾而不是当年披露

## 5. 本地股东信能直接支撑哪些增强

你这个文件夹里的年报，已经足够把下面三层做起来：

- `逐页引用`
- `年度持仓表格快照`
- `同一家公司跨年份的 narrative timeline`

也就是说，哪怕先不接股价 API，不接 13F，也能明显比现在的网页更深。

尤其是下面这些内容，本地语料就能直接做：

- 1988 年伯克希尔对市场机会集的判断
- 1988-1994 年可口可乐持仓表格里的成本和市值变化
- 2022 年对可口可乐、美国运通的分红回顾
- 2023 年对「为什么不卖」的最新表述

## 6. 哪些地方仍然需要补外部资料

如果要把案例做到接近研究笔记级别，还需要额外补三类东西：

- `1977 年之前的合伙人信`
- `更细颗粒度的价格序列`
- `少数没有在股东信中充分展开的交易细节`

例如美国运通最经典的 `1964 salad oil scandal` 首次买入，单靠本地 PDF 只能从后来回忆里反推，不能完整还原当时环境。

## 7. 一个务实的迭代顺序

最建议的顺序不是一次性做 61 家公司，而是：

1. 先做 `5-8` 个最典型 case
2. 先让每个 case 都有 `一页结论卡 + 时间线 + 证据账本`
3. 再补价格序列和可视化
4. 最后再把所有公司页升级为案例入口页

第一批最值得做的：

- 可口可乐
- 美国运通
- 华盛顿邮报
- 盖可保险
- 喜诗糖果
- 富国银行
- 苹果
- 西方石油
