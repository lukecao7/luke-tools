# 房间布局规划

基于当前户型的交互式房间规划画布工具，纯本地运行，无需安装依赖。

## 打开方式

[在线打开房间规划](https://lukecao7.github.io/luke-tools/room-planner/)，也可以双击 [index.html](index.html) 离线使用。首次打开会载入分享时的实际布局，共 26 件物品、0 个插孔。之后优先读取当前浏览器的存档，每位使用者可以独立调整。

[房间布局副本（JSON）](room-layout.json) 包含物品名称、尺寸、位置、朝向和方案设置。可以直接分享这个文件，由对方在「···」中导入。户型墙体、飘窗和门洞尺寸随本工具一起提供。页面内嵌了同一份布局，用于离线打开。

## 从画布开始

轻点要摆放的位置，在图上选「方形物品」「插座」或「更多」。点已有物品可查看名称、尺寸和朝向，点「编辑」可修改，按住拖动可调整位置。桌面右栏在取消选择或删除后留空；手机只在选中物品时弹出信息卡。

点底部方案名可以切换或复制方案。右上角「···」提供 JSON 导入和导出。

在物品清单或编辑面板点「多选」，可以在图上点选或在清单里勾选多件物品，再点「删除所选」。电脑上也可按住 Shift 点选。删除后面板继续打开，一次撤销即可恢复整批。

## 主要功能

- **精绘无字矢量户型**：按原户型实测比例还原外墙、承重柱、门窗、开门弧线与固定厨卫设施（可按需开关），支持切换上传自定义底图并校准比例尺。
- **添加设备 / 家具**：支持按长×宽（cm）或按占地面积（㎡）反推尺寸添加，支持在画布上直接框选绘制，内置常用家具预设。
- **墙面插孔标注**：支持五孔插座、16A 大功率、网口/光纤、开关与地插点位；选中设备时自动显示到最近电源插座的距离。
- **挪动与 90° 旋转**：拖拽自动吸附对齐，支持悬浮按钮或快捷键 `R` / `⇧R` 每次旋转 90°，方向键 1 cm / 10 cm 微调，支持多方案复制对比、撤销重做、导出 JSON 与高清 PNG。

## 原图布置

分享方案名为「原图布置」。其中的床、书桌、三个衣架、猫架及其他家具和厨卫设备均可单独编辑。已确认的尺寸按实测值绘制，其余原图物品按图片比例估算。墙柱、门窗和管道井属于底图。

点底部方案名可切换或复制方案。想在已有存档的浏览器中重新载入分享版，可先导出当前项目，再导入房间布局副本。

从阳台上方窗内沿量到两侧短墙，左侧净深为 115 cm，右侧为 94 cm。左短墙向室内伸出 39 cm、厚 25 cm，右短墙从中隔墙向左伸出 48 cm。卧室 A 从左侧短墙下沿到卧室下墙内侧为 260 cm。左下角衣柜沿下墙横放，长 131 cm、深 60 cm。打开已有「原图布置」会自动载入这次衣柜修正，之后可单独编辑或删除。

客厅左墙从卧室隔墙下方起，依次摆放宽 50 cm、深 60 cm 的冰箱和两个长 120 cm、深 40 cm 的置物架。三件正面朝向客厅，紧挨摆放共占墙长 290 cm。已有「原图布置」会在首次载入新版时更新这三件物品，之后可分别调整。

卧室 B 飘窗从窗内沿向室内进深 81 cm。窗台右下角的固定墙块沿右墙长 47 cm，向室内伸出 27 cm。精绘户型按家具的实际占地检查这两处禁放区。载入旧方案时，压线的家具会移出禁放区，保留尺寸和朝向。

入户门净宽 95 cm，左侧卧室 A 的门净宽 86 cm，右侧卧室 B 的门净宽 82 cm。门洞、门扇和开启弧线使用同一组实测尺寸。
