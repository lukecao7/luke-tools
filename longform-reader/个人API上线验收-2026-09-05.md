# 个人 DeepSeek API 上线验收

已发布版本：`20260905-deepseek-byok`。生产部署：`dpl_FUkjPb91aF7pyJtVER7TZRfnrvrE`。

## 本次交付

- 用户在首页、阅读页和摘要页绑定自己的 DeepSeek Key，界面明确说明默认使用 DeepSeek V4 Flash，以及模型调用会消耗个人额度。
- Key 保存在当前浏览器，调用时临时转发给服务端；不会写入报告、云存储或日志。线上缺少个人 Key 时不会回退到服务器的共享 Key。
- 绑定时检查余额；调用前检查可用额度。余额不足时显示持续提醒和充值入口，运行中收到额度不足错误时保留已有结果。页面关闭后不发送邮件或推送。
- 报告、原 PDF 和示范文档按浏览器的独立凭据隔离存放在私有云存储。解绑 Key 不删除已保存的报告和摘要。
- 保留原有网站访问密码，未新增个人账号。不同设备和浏览器之间不会自动同步；清除本站浏览器数据会丢失个人 Key 和阅读空间入口。
- 云端单次上传合计不超过 4 MB，本地版仍为 25 MB。
