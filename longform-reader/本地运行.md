# 本地运行

双击项目中的 `启动长文伴读.command`，浏览器会打开 http://127.0.0.1:4173/ 。重复打开会复用已有服务。终端启动方式为 `npm run start:background`，后台运行后可以关闭启动窗口；停止服务用 `npm run stop:background`。

分析、翻译、解释和摘要通过 OpenAI Responses API 调用 GPT 6.1 Sol，默认中度推理、标准速度。处理仍需联网，电脑与本地服务需要保持运行。

首次配置：在 ChatGPT「设置 → 账单」或 API Platform 账单页领取 Pro 的 API 额度，选择自己的 Personal 组织；然后创建该组织下项目的 API Key。在本机 `.env.local` 中设置 `OPENAI_API_KEY=你的密钥`，服务启动时会自动读取。密钥只由后端读取，不发送到浏览器，也不进入 Git。不要把密钥粘贴到聊天或分享文件中。配置后重启服务。

Pro 200 的完整账期额度为 $200，首期按剩余时间折算，当期到期不结转。领取与创建密钥是两步；仅登录或选中 Personal 不表示已到账。请在 API Platform 的 Credit grants 中核对。此额度不能用于 Codex CLI，所以本地启动器已切换为直接调用 Responses API。API 失败或缺少密钥时不会自动消耗 Codex 订阅额度。

材料、PDF、摘要和阅读进度保存在 `data/spaces/` 中，沿用原浏览器的阅读空间。已有 DS 论文不需要重新上传。请保留浏览器网站数据；清除它会丢失阅读空间的入口。

本地版只监听 `127.0.0.1`。本次接入用于本地服务，线上模型处理仍关闭，`vercel.json` 已关闭 Git 推送自动部署。运行日志在 `.runtime/local-service/` 中。API 响应存储关闭（`store=false`），取消导入会中止正在进行的 HTTP 请求。

论文中的独立公式保留 PDF 原有排版与编号；译文按原文段落和页面摆放，无需重新上传旧材料。公式保持清晰原貌，不做 LaTeX 猜测或重新翻译。普通文章可以通过 `OPENAI_REASONING_EFFORT=low` 使用轻度推理。

如需手动回退旧接入，可停止后台服务，再通过 `AI_PROVIDER=codex npm start` 启动；默认启动器始终使用 OpenAI API。
