# 本地运行

在项目目录运行 `npm run start:background`，然后打开 http://127.0.0.1:4173/ 。重复运行不会创建多个服务。

服务由 macOS 后台托管，不依赖 Codex 工具会话或终端窗口。当前登录期间持续运行；注销或重启电脑后，再运行上述命令。没有设置开机自动启动。

停止服务：`npm run stop:background`。

日志：`.runtime/local-service/stdout.log` 和 `.runtime/local-service/stderr.log`。材料与阅读进度仍存放在 `data/`，停止服务不会删除数据。

开发时可先停止后台服务，再运行 `npm run dev`；避免两个服务占用同一个端口。
