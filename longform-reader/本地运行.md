# 本地运行

双击项目中的 `启动长文伴读.command`，浏览器会打开 http://127.0.0.1:4173/ 。重复打开会复用已有服务。终端启动方式为 `npm run start:background`，后台运行后可以关闭启动窗口；停止服务用 `npm run stop:background`。

分析、翻译、解释和摘要使用这台电脑上已登录 ChatGPT 的 Codex CLI，默认 GPT 6.1 Sol、轻度推理、标准速度。读者无需填写 API Key 或充值。处理仍需联网，使用本机 Codex 账号的额度；电脑与本地服务需要保持运行。

macOS 优先使用桌面应用附带的新版 CLI，避免旧版本不支持模型。其他环境使用 `codex` 命令，也可以通过 `CODEX_BIN` 指定路径。先运行 `codex login status` 检查是否已登录。

材料、PDF、摘要和阅读进度保存在 `data/spaces/` 中，沿用原浏览器的阅读空间。已有 DS 论文不需要重新上传。请保留浏览器网站数据；清除它会丢失阅读空间的入口。

本地版只监听 `127.0.0.1`。Vercel 无法运行本机 CLI；本次接入用于本地服务。运行日志在 `.runtime/local-service/` 中。
